어느 시간대를 자동 확정할지 사장님이 정합니다

대부분의 예약 도구는 매장 전체에 하나의 규칙만 적용합니다. BookingYou는 시간대별로 설정할 수 있어, 평일 오후는 즉시 확정, 토요일 저녁은 사장님 승인으로 운영할 수 있습니다.

규칙은 앱이 아니라 서버에서 실행됩니다

시간, 정원, 휴무일, 승인 규칙은 데이터베이스에서 검증되므로 변조된 앱으로도 우회할 수 없습니다.
