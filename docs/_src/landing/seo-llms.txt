# BookingYou

> BookingYou is a booking management app for appointment-based small shops and independent service providers. The public pages below are the source for these product facts and industry-specific examples.

## Product facts

- Core booking-management features are free; BookingYou charges no booking commission. The Pro plan is planned, not currently available, and its pricing has not been announced.
- Merchants manage calendars, manually entered bookings, rescheduling, reminders, opening hours and confirmation rules.
- Customers can submit a booking through a merchant link or QR code in a browser without installing the app. Availability depends on the merchant enabling web booking.
- Web booking submissions always require merchant confirmation. App bookings follow each time slot's instant-confirmation or approval setting.
- Merchants can use the iOS/iPadOS or Android app. The website and web booking pages are available in a browser; the website is not a desktop merchant-management app.
- Contact: contact@bookingyou.app
