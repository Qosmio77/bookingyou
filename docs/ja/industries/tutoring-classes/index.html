個別指導・教室

現場で起こる予約の悩みから考える。

01

科目の確認後、空き時間の相談が続く

科目やコースごとにサービスを作り、対象レベルと所要時間を明記。適した授業を選んでから日時を申し込めます。

02

体験前の情報が少なく準備しにくい

学年や相談したい内容を任意の備考に記入してもらい、講師が承認前に確認します。

03

振替の連絡が別々の会話に埋もれる

同じ予約の日程を変更。電話で決めた振替も登録して、受講者と日時を一か所で確認します。

04

定員も授業準備の時間も確保したい

一回の受け入れ人数を設定し、教材準備、休憩、教室の片付けに必要な時間を空けておきます。

01 / お客様の操作

お客様はどう予約する？

  1. 保護者や受講者が授業を選ぶ

    教室のリンクを開き、科目・レベル・体験の種類を確認してから空き枠を選びます。

  2. 連絡先と必要な情報を入力する

    氏名と電話番号を入力。保護者の代理予約では、受講者の呼び名や学年を備考に書けます。予約に不要な個人情報は記入しません。

  3. 専用リンクで承認を確認する

    申し込み後は講師の確認を待ちます。リンクを保存し、振替が必要な場合は教室へ相談します。

02 / お店の操作

お店はどこで予約を確認する？

  1. 承認待ちの授業と備考を読む

    予約一覧でサービス、日時、連絡先、備考を確認し、体験か通常授業かを把握します。

  2. 対象レベルと授業体制を確認する

    科目、レベル、定員、教室の空きを照合。不明点は保護者に確認してから承認します。

  3. カレンダーで授業と振替を管理する

    確定した授業を日々確認。振替後は最新日時を確認し、授業後に完了へ更新します。

申し込み → お店が確認 → 予約確定

ウェブ予約はお店の承認後に確定します。アプリでの予約管理、チャット、リマインダーを利用したいお客様はアプリをご利用ください。ウェブからの申し込みでは専用リンクを保存してください。

この業種でよくある質問

保護者が子どもの代わりに予約できますか？

保護者を連絡先としてウェブから申し込めます。備考に受講者の呼び名や学年を補足し、実際の受講内容は教室で確認してください。

成績や宿題も管理できますか？

本ページは予約と授業時間の管理を紹介しています。成績、宿題、出席集計、月謝管理を含む総合学習管理システムではありません。

学期全体の予定が自動で作られますか？

このフローは一回ごとの予約です。固定の授業は、合意した日程を個別に登録・確認してください。
