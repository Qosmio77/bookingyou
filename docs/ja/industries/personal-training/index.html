パーソナルトレーニング

現場で起こる予約の悩みから考える。

01

空き時間の問い合わせが何往復も続く

予約リンクを共有すれば、利用者が公開中の枠を確認して申し込めます。

02

個別指導とグループで定員が違う

サービスを分けて受け入れ人数を設定。グループは会場と開催内容も確認してから受け付けます。

03

別会場への移動時間が足りない

移動、準備、休憩の時間を予約対象から外し、実際に指導できる時間だけを公開します。

04

変更前の時間がメモに残ってしまう

同じ予約の日程を変更し、カレンダーで最新の予定を確認。ウェブ利用者は専用リンクで状態を確認できます。

01 / お客様の操作

お客様はどう予約する？

  1. 体験か通常セッションを選ぶ

    リンクを開き、場所、所要時間、料金を確認して希望のサービスを選びます。

  2. 出席できる日時を申し込む

    空き枠を選択し、氏名と電話番号を入力。初回利用など、準備に役立つ情報を備考に書けます。

  3. 承認後に予定を確定する

    ウェブ申し込みはトレーナーの確認後に確定。専用リンクを保存し、日程変更が必要ならトレーナーに連絡します。

02 / お店の操作

お店はどこで予約を確認する？

  1. 新しい申し込みを確認する

    お店側の予約画面で承認待ちを開き、利用者・セッションの種類・日時・備考を確認します。

  2. 会場とスケジュールを照合する

    確定済みの予定、移動、休憩を確認。グループは定員と会場を照合してから承認します。

  3. 指導前後の状態を更新する

    確定一覧をもとに接客し、変更は同じ予約から処理。セッション後は完了に更新します。

申し込み → お店が確認 → 予約確定

ウェブ予約はお店の承認後に確定します。アプリでの予約管理、チャット、リマインダーを利用したいお客様はアプリをご利用ください。ウェブからの申し込みでは専用リンクを保存してください。

この業種でよくある質問

毎週の予約を自動で作れますか？

このガイドは一回ずつ日時を選ぶ予約方法です。定期的な利用は、合意した日程をトレーナーが個別に登録・確認してください。

回数券の残数も自動で減りますか？

予約の完了はセッションの実施を示します。このページでは回数券の消化や会費決済を保証していません。契約や支払いは現在の運用に合わせて管理してください。

グループレッスンにも使えますか？

サービスの定員と受付時間を設定できます。実際の受付方法はお店の設定によります。会場や器具、指導内容の確認はトレーナーが行ってください。
