01 / 客户预约

客户如何预约？

  1. 家长或学生选择课节

    打开老师或工作室的链接，按科目、程度或试听类型选择服务，再查看可用日期。

  2. 填写联系人资料

    填写姓名和联系电话。家长代约时，可在备注中补充学生称呼、年级及一般学习需要，无需填写与预约无关的个人资料。

  3. 保存链接，查看确认状态

    提交后等待老师确认，并保存预约链接。如需补课或调整时间，请先与老师协调。

02 / 商户管理

商户如何查看和处理预约？

  1. 查看待确认课节与备注

    商户端预约列表显示服务、时间、联系人及备注，先区分试听、正课或其他课程安排。

  2. 确认程度与授课安排

    核对科目、学生程度、班级名额及教室时间。如需补充资料，先联系家长，再确认申请。

  3. 通过日历跟进上课与补课

    每天查看已确认课节；改期后核对最新日期，授课结束后标记完成，方便日后查阅。

提交申请 → 商户确认 → 预约生效

这个行业还有哪些预约注意事项？

家长可以为孩子预约吗？

可以由家长作为联系人提交网页申请，并在备注中补充学生称呼或年级。老师确认时再核对实际授课安排。

可以作为完整的学生管理系统使用吗？

本页介绍课程预约及时间安排，并不代表支持成绩、作业、出勤统计或学费管理。这些记录需根据您的教学流程另行处理。

会自动生成整个学期的课表吗？

此流程以逐次预约为主。固定课程可根据约定日期逐次创建并确认，不应假设提交一次就会自动排好整个学期。
